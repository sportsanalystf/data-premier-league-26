# data/raw

The organisers' input files are not stored in this repository. To rebuild, copy them here:

| File | Source |
|---|---|
| `Data_Premier_League_Prelims_Dataset.csv` | DPL 2026 preliminary-round dataset (ball-by-ball IPL 2023-24) |
| `IPL_Auction_2023_24.xlsx` | DPL 2026 auction sheet |
| `Data_Dictionary.pdf` | DPL 2026 data dictionary (reference only) |

Everything else in the project is rebuilt from these by `Rscript run_all.R`.
